Tips Konfigurasi
  • Gunakan openrouter/free untuk testing tanpa biaya.
  • Site URL & App Name membantu OpenRouter melacak penggunaan.
  • System prompt yang jelas menghasilkan jawaban lebih akurat.
  • Simpan API key dengan aman — jangan bagikan ke publik.
